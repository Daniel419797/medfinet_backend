# NXP TagWriter demo card

This flow is for demonstrations with a blank NFC Forum Type 2 card and the
Android **NXP TagWriter** application. It is intentionally separate from
Medfinet's production NTAG215 provisioning workflow.

The card contains one opaque, revocable URL. It never contains the child's
name, Medfinet ID, vaccination history, allergies, or any other clinical data.
An authenticated Medfinet worker, an active organization membership, a
registered browser signing key, applicable consent, and online backend checks
are still required before a record is returned.

## Create the card URL

1. Sign in to Medfinet as an owner or administrator.
2. Open **NFC operations** and find **Connect a card with NXP TagWriter**.
3. Select the child and choose **Create TagWriter URL**.
4. Copy the URL immediately. Medfinet stores only its hash, so it cannot be
   displayed again after the page is refreshed.

## Write the card in NXP TagWriter

1. Enable NFC on the Android phone and open **NXP TagWriter**.
2. Select **Write tags**.
3. Select **New dataset**.
4. Select **Link/Bookmark**.
5. Paste the exact URL generated by Medfinet.
6. Do not add a **Launch Application** record or any second record.
7. Select **Write**, then hold the card against the phone's NFC antenna without
   moving it until TagWriter reports success.
8. Do not make the card read-only during the first write. Test it first.

## Retrieve a permitted record

1. On an NFC-enabled Android phone, tap the card. The public page confirms only
   that the opaque card link is active; it never displays child data.
2. Sign in as an authorized Medfinet worker if prompted.
3. Open **NFC Scanner**, select **Start scanner**, and tap the card again.
4. The browser registers or uses its existing device signing key. The backend
   verifies the worker, organization, card token, consent and card lifecycle,
   records an audit event, and returns only the permitted summary.

## Important limitation

TagWriter writes a static NDEF URL. That URL can be copied and cannot prove
that the original physical card is present. TagWriter demo cards therefore:

- are labeled `AUTHENTICATED_STATIC_NDEF_DEMO`;
- require an internet connection and cannot use offline record resolution;
- must not be treated as production identity assurance; and
- should be revoked after the demonstration.

Production cards must use the approved raw-NFC station flow, which binds the
chip UID and originality evidence, configures the NTAG215 counter mirror, and
verifies write protection before activation.
